**Scope-**
This program provides a simple programming system which provides the user with simple features like adding, viewing, searching, issuing, reutning books and fine calculation 
It is a simple way of programming in a library without engaging the user in typical tasks like online accounds, password creation etc.
**Target users:**
Librarians and staff- ones who need a quick simple way to manage lending issuing and returning of books.
School and Local libraries- who are looking for an easy simple way to manage their books
Beginner coders- Students learning python who want to learn how to build a simple inventory program.
**Key Features:**
add new books,view currnt collection and add titles
issue books as instructed by customers and easy return
automatically charges fine if the customer returns the book late
searches for the book title customer inputs and provide information about whether the book is available or not.
saves all changes to ensure the data is not lost.
