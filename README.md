# Python__Project
Library Management System

Overview- project shows a simple library management system to manage book issuing, searching, viewing, returning and fine calculation.

Features- 
**Managing books:** provides feature to view books searching them and issuing the required books.
**Borrow and return:** it provide us feature to borrow book as per user choice and to return the issued books.
**Late fee calculation:** calculates fine for the customers who return the books late 

Technology and tool used- **Python** is the primitive programming language used to wrote the project.

Instructions for testing-
**Adding books:** 
choose option 1 for adding the book you would like to add
write the name of the book oyou want to add
the book will be added with a message that the book is added
**Issuing books:** 
choose opton 2 for issuing the books you want and enter the name of the books
the required book will be issued 
**Searching book:**
choose option 3 for searching the book you want and enter the name of the book.
If the book is available in the library the message will be printed for the same
**View books:**
choose option 4 for viweing the list of books available in the library and press enter.
the list of the available books will be displayed.
**Return books:**
choose option 5 if you want to return the books you issued and press enter.
The book will be added back to the library and if returned late, fine will be calculated depending upon number of days.
**Exit library:**
choose option 6 if you want to exit the library and a thnakyou message will be printed
if any other choice is entered a message for invalid choice will be printed
